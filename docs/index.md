## Get started

1. **Download the source ZIP** using the button above and extract it.
2. **Install for VS Code / GitHub Copilot** by copying `.github/skills/medtrans` from the extracted folder to `%USERPROFILE%\.copilot\skills\medtrans`. Or open the extracted repository folder in VS Code to use the workspace skill.
3. **Follow the tutorial** to prepare your lecture, use the skill, and review the finished Word document.

The download contains the complete skill folder, including `SKILL.md`, course shells, palettes, helper scripts, and references. Keep the folder contents together.

## Built for MD201–MD207

MedTrans includes matching shells and palettes for MD201, MD202, MD203, MD204, MD205, MD206, and MD207. The supplied lecture remains the content authority; always compare the generated reviewer with the original slides before sharing.
