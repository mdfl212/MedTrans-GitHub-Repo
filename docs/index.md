MedTrans helps you turn medical lecture slides into editable, source-faithful Word reviewers.

## Get started

[Read the step-by-step tutorial]({{ '/tutorial/' | relative_url }}) to prepare your lecture, install or load the MedTrans skill, prompt your AI assistant, and check the finished reviewer.

[Download the latest skill ZIP](https://github.com/mdfl212/MedTrans-GitHub-Repo/releases/latest/download/MedTrans_VSCode_Copilot_Skill.zip) or [browse all releases](https://github.com/mdfl212/MedTrans-GitHub-Repo/releases).

## About the package

The MedTrans skill supports MD201–MD207. It includes course-specific Word shells, palettes, optional helper scripts, and quality-check guidance. The current lecture is always the content authority, and each generated reviewer should be checked against its source before sharing.

[View the repository on GitHub](https://github.com/mdfl212/MedTrans-GitHub-Repo).
