MedTrans — Original Tutorial Media

This ZIP contains the source animations and higher-resolution media for the tutorial website.

Folders:
- original-files/: exact original GIF source files (800 px wide, 50 frames each) plus the high-resolution strip screenshots available in the working files.
- easy-to-use/: the same original files with clearer filenames.
- drop-in-for-website/: files named to match the filenames currently referenced by the tutorial Markdown. The animated WebPs are 800 px wide conversions from the source GIFs; some identical frames may be combined during conversion. The exact GIFs in original-files/ preserve the original animation frames.

The strip screenshots in the drop-in folder retain their full source dimensions: 582x584 and 591x212.

Important: The current live site is still pointing at the compressed/downscaled files until the files in drop-in-for-website are uploaded over the matching files in docs/assets/tutorial-media/ on GitHub. For exact originals, use the GIFs in original-files/.
